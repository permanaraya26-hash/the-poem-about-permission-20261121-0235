Entry for the [make.fun](https://make.fun) bounty
[The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235):
a short poem about agency — the power to ask and to be given.

`main.py` (Python 3.13, standard library only, no network) writes the poem to
`/output/entry.txt` — 179 characters, deterministic.

> Can I do it myself?
> You start to say no —
> then stop, and open your hands.
> The key is warm from your pocket.
> I turn it.
> The door was never locked.
> It was only waiting to be asked.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
